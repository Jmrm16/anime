Responsive single-page web platform dedicated to exploring, filtering, and cataloging anime series, episodes, and multimedia content. Developed with **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## ✨ Features

- **Modern Catalog Grid:** Dynamic card layouts displaying artwork, ratings, genres, and synopsis.
- **Real-Time Search & Filtering:** Debounced query matching across titles, status, and tags.
- **Multimedia Player Layout:** Clean player viewport with episode selection sidebar and volume controls.
- **Fully Responsive Design:** Optimized for mobile screens, tablets, and wide monitors.

---

## 🛠️ Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer

---

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/Jmrm16/anime.git
cd anime/ANIME/frontend

# Install dependencies
npm install

# Start local server
npm run dev
```
